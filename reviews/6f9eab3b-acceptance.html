Flag 1 — the newer board's Valve source URL is invalid

The board output contains the malformed VRS URL in 88 of 89 fixture rows. The `2aa280…` segment is the file’s Git blob SHA, not a commit SHA; a GitHub blob/{ref}/path URL needs a commit, branch, or tag ref.

Broken URL emitted:
Valve standings at blob/2aa2805394fbc68f36a5752a5b16026f2ab2fed5/…

The official GitHub REST API request for commit 2aa280… returned HTTP 422, “No commit found for SHA.” The contents API at a valid commit confirms that `2aa280…` is the file-object SHA, which explains the mistaken URL component.

Verified corrected URL:
Valve standings at commit eec4853d7bcf0f1f7efe7f0d901234bef7e98b75

The commit API resolves. The official contents API returns the expected path, 77,872-byte file, and blob SHA `2aa280…`. The verified file is dated 2026-10-05; its corrected URL is used by the executive board.
