Where each number comes from

1. The match list

The slate is read from the official Hotspawn pick'em pages. Only fixtures that still show a "Locks in" countdown are treated as pickable. Times are stated in UTC: the page's own countdown is subtracted from the fetch time to confirm the offset, and EGamersWorld independently lists the same kickoffs.

2. Market probability (external bookmaker line)

For a two-way decimal price pair (oA, oB) the overround is removed proportionally:

pA = (1/oA) / (1/oA + 1/oB), pB = 1 - pA, margin = 1/oA + 1/oB - 1.

The margin is published on every row so the size of the bookmaker's edge is visible. Prices are read from EGamersWorld's bc.game block. Where EGamersWorld shows its equal placeholder pair (1.80 / 1.80) the row is left blank, not converted.

3. Our own line (Valve Regional Standings)

Each team's rating is its points total in Valve's official Regional Standings file live/2026/standings_global_2026_10_05.md (380 rows, pinned commit eec4853d7bcf0f1f7efe7f0d901234bef7e98b75, sha256 df96e7fc3cd91a2687ec08cac0128e50cc4e4e55346581679572e881d79ae61b). The map win probability uses Valve's own published Glicko expected-win function, with the constants taken from Valve's repository model/glicko.js: Q = ln(10)/400 and g = 1/sqrt(1 + 3·Q²·rd²/π²) with Valve's default rd = 75, giving g = 0.972821:

E = 1 / (1 + 10^(-g·(rA - rB)/S))

The scale constant S. Valve's source comment says "rank delta of 400 points = 90% chance of victory", i.e. S = 400. Applied directly to the published standings point totals that is far too confident — it puts Legacy (VRS #2) over PARIVISION (VRS #36) at 99.7% for a Bo3 where the bookmaker line is at 54.6%. The standings point column is a compressed scale, not a raw Glicko rating. We therefore fit S by minimising cross-entropy against the external market's implied per-map probabilities on every fixture that has both a market line and two rated teams (23 fixtures). The fit is a deterministic one-parameter grid search:

S = 1122 · in-sample cross-entropy 0.6348 · leave-one-out cross-entropy 0.6365 · the market's own entropy on the same rows 0.6214 · a coin flip scores 0.6931.

What that means, stated openly. The own line is a market-calibrated rating model. It is used to produce a probability where no bookmaker line exists. On rows that do have a market line, the market-versus-own difference is a consistency check, not an independent validation — the two are not independent of each other.

The series probability is E for a Bo1 and E³ + 3·E²·(1-E) for a Bo3. The format is read from the EGamersWorld fixture and linked on that row; where no format is published, only the map probability is shown and the row is flagged.

A team with no row in Valve's file gets no rating and no own line — the value is left blank and flagged, never estimated. Name mappings between Hotspawn and Valve are only admitted with evidence (identical opponent plus identical kickoff on an external page, or a named official roster) and every one of them is listed on the Flagged page.

4. The pick

External market line first; our own model only where no external line exists (labelled on the row); no pick where neither exists. Where the market and our model disagree on the winner, the row is flagged and the market pick is published.

5. What is never used

Hotspawn's crowd pick percentages are recorded on the all-matches page as audit metadata and appear in no calculation anywhere on this site.
