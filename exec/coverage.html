One row per open CS2 fixture in the captured Hotspawn payload, one column per board in this repository. "price" = the board publishes a bookmaker price for that match, "own line" = it publishes a line built from official ratings, "pick" = it names a side. A dash means that board has nothing for that match — which is the gap this page exists to show.
