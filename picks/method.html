Method

  1. Fixtures. Every row of the live CS2 pick'em lobby (play.hotspawn.com/cs2-pickems) is listed. Start times are UTC. Lock time = start - 6 min (lock_offset_sec 360 in the Hotspawn data).
  2. External line. Decimal 1X2 prices shown on EGamersWorld match pages and event schedules (aggregated headline prices). Placeholder 1.80/1.80 pairs are discarded. De-vig is proportional: p_A = (1/odds_A) / (1/odds_A + 1/odds_B). The overround is shown.
  3. Own line. Valve's Regional Standings curve, P(A) = 1 / (1 + 10^(-k*(pts_A - pts_B)/400)), with k = 0.4568 (the calibrated slope adopted in model/input/vrs/calibration.json). Points are read from Valve's 2026-10-05 standings file. A team with two Valve rows, or no Valve row, gets no own line.
  4. Pick. The higher external probability. If no verified external line exists, the higher own probability is used and labelled "own model only". If neither exists, there is no pick.
  5. Not used. Hotspawn crowd percentages (the 'picked' figures) are never read as inputs or shown as probabilities. HLTV world ranks were not used in this session.
  6. Limits. The external line is one headline price pair per match, not a bookmaker consensus. Prices move; the capture window is stated on every page. Own lines use the latest published Valve standings (2026-10-05).

Reproduce: python3 picks/build.py from the repository root. Inputs are the hand-entered values at the top of that file, each with its source.
