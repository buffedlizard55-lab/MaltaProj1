Method

External line. EGamersWorld CS2 matches listing headline odds for both sides (one reading per row, 2026-10-13 ~22:00 UTC; the reading and link for each row are in picks/data/egw_listing_2026-10-13.csv). Implied probability = 1/odds. The two-way pair is normalised: p_A = (1/o_A)/((1/o_A)+(1/o_B)). Overround is shown per row. Prices of 1.80/1.80 or with no opponent name are treated as placeholders and left blank.
Own line. The Valve Regional Standings points of each roster, through the calibrated model in model/ (session 91eff436). Values are read from model/data/lines.csv as published. They are not re-run here. Blank where the team cannot be resolved to one official row.
Pick. Pick = side with higher external probability. If no external line exists, the own-model side is shown and labelled "own model only". If neither exists, no pick.
Times. Lobby display is EDT. Converted to UTC. Lock = start − 6 min (see Flagged IR-9569-09). A row whose lock time has passed at the as-of time is shown as Locked and is not pickable.
Not used. Hotspawn crowd percentages are never an input or displayed. HLTV community %, Polymarket, and any other prediction source are not used.
Build. python3 picks/build.py regenerates every page and data/fixtures.csv from the inputs above.
Probabilities: external bookmaker prices (EGamersWorld, de-vigged) and our VRS model. Hotspawn crowd % is never used. As of 2026-10-13 22:00 UTC. Repository home
