Coverage gaps

The Hotspawn lobby advertises 86 total matches (60 this week, CS2 + LoL tabs). The server-rendered lobby page (which we can reliably scrape without headless browser execution) exposes only the "Closing Soon" and "Upcoming" sections (≈26 matches). The remaining matches (additional CCT, DACH, DraculaN, European Pro League, LG UltraGear, Rainhas do Clutch, Svenska CS-Ligan, Urban Riga Open, Thunderpick South America, plus all LoL matches) are loaded client-side via JavaScript and could not be enumerated from the static fetch. These are NOT listed with fabricated data; they are noted as coverage gaps here and should be added once the API endpoint or headless scrape is available. No values were inferred.

LoL tab: matches were not enumerated in the static render; no LoL odds were scraped. The user can navigate to LoL via Hotspawn's tab; those rows are missing from this dashboard until a JS-capable scrape is performed.
