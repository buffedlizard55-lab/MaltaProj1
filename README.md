# MaltaProj1 — Hotspawn Pick'em betting-line analysis

Live site (GitHub Pages, from `docs/`): landing dashboard + category tables.
Start at `docs/index.html` locally, or the Pages URL after deploy.

- `data/matches.csv` — 26 verbatim Hotspawn fixtures (2026-10-13 snapshot), with team names, tournament category, Hotspawn match URL and a crowd-% audit snapshot (never a probability).
- `data/external_lines.csv` — one row per source reading (Polymarket cents, eGamersWorld decimal), each with status accepted / indicative / rejected and a source link.
- `data/analysis.csv` — generated by `scripts/model.py`: own line, external mean, pick and pick basis.
- `data/ratings.csv` — HLTV rank inputs, each sourced. `data/lines.csv` — bookmaker outrights (Thunderpick WC). `data/tournaments_inventory.csv` — all 85 CS2 fixtures by tournament count.
- `scripts/model.py` — reproducible own model `rating=2000-300*log10(rank)`, Elo logistic, plus no-vig external and pick rule. Writes `data/analysis.csv`. Run: `python3 scripts/model.py`.
- `scripts/build_docs.py` — regenerates every page in `docs/` from `data/`. Run: `python3 scripts/build_docs.py`.
- `docs/flagged.html` — Flagged for Review (F-01…F-15). `docs/sources.html` — S-01…S-18. `COORDINATION.md` — task board/log.

Hotspawn crowd % is never used as probability. Analysis only, not betting advice.
