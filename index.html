Executive summary

Picks and win probabilities for every CS2 match on Hotspawn.

Hotspawn tells you which matches exist. It does not tell you who wins, and its crowd pick percentages are never used here. Every probability on this site comes from an outside betting line or from a line we originate ourselves from the official Valve and HLTV ratings — with the source printed on the row, and nothing filled in when no source confirms a value.

How a pick is produced

  1. Outside bookmaker, priced — the book’s own public moneyline, de-vigged proportionally. Highest confidence, labelled T1/T2.
  2. Secondary listings & prediction markets — where the big books skip a low-tier match, aggregator listings (bo3.gg-relayed prices, EGamersWorld/bc.game) and Polymarket implied probabilities are used, each labelled and linked.
  3. Our own line from official ratings — Valve Regional Standings points, and the official HLTV world ranking for the teams VRS does not list, converted to the stated series length. T3/T5.
  4. Official bound — if a team appears in no official list at all, the last place in that same list is used as a conservative ceiling and the row is flagged T4.
  5. Nothing confirmed — the number stays blank and the row goes on the flagged page. Hotspawn’s crowd percentages are never an input at any tier.
No manual input is needed. A scheduled GitHub Actions job re-reads Hotspawn and every outside source every four hours, rebuilds these pages, re-runs the invariant suite and only then replaces the published snapshot — so a failed read leaves the last good board standing instead of a half-updated one. See the refresh status.

Reading this on a phone

The picks table is built as cards for narrow screens: fixture, both percentages, the pick in large type, then the basis and its source link. Anything that is not a real price says so on the row (our line, bound, prediction market). Analysis only — not betting advice, and no number here is an offer you can take. Prices move; each row prints the minute it was read.
