Hotspawn Pick'em — line analysis

Independent, source-linked analysis of the play.hotspawn.com Pick'em board (CS2 + League of Legends). Fixtures come from the board itself; probabilities come only from outside bookmaker prices, de-vigged by this project. Hotspawn's own crowd percentages are never used as a probability.

Complete slate & external lines380 fixtures

Every match on the board (86 CS2 + 294 LoL) read from the Pick'em pages' own server-rendered payload, with exact UTC start/lock times; 17 fixtures carry a real external price and this project's de-vigged line; the rest are blank on purpose and listed on the Flagged page.

Tournament dashboards (earlier sessions)

Per-event pages for the Thunderpick World Championship, Stake Pulse Beat III, CCT Europe, ESL Challenger and the lower tiers, with an independent rank-based model and its own flagged/sources pages.

Flagged for Review

Discrepancies between the board's own fields, sources that refuse automated reads, refused blanks and live-market drift — each with a link for manual review.

Methodology

How the fixture list, the external prices and the de-vigged probability p = (1/oA) / (1/oA + 1/oB) are produced — and exactly what is left blank instead of guessed.

Sources

Every source used (Hotspawn Play, EGamersWorld/BC.Game, HLTV, Liquipedia) and the CI probe results showing which odds sites can and cannot be read programmatically.

Review file

lines/analysis.csv — one row per fixture with ids, times, crowd metadata, price status, odds, de-vigged probabilities, source URL and capture time.
