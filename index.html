Hotspawn Pick'em — line analysis

Independent, source-linked analysis of the play.hotspawn.com Pick'em lobby. Fixtures are read from the board's own server-rendered payload; probabilities come from outside sources only — external bookmaker prices, de-vigged here, and this project's own model built on official rating data (HLTV world ranking, Valve Regional Standings). Hotspawn's crowd percentages are never used as a probability.

Every table row carries a link to the page it was read from. A value that could not be confirmed stays blank and is listed on the Flagged for review page — nothing is inferred.

Repository README

Where everything lives and how to reproduce the generated pages.
Policies kept by every page here. Hotspawn's crowd percentages are never converted into a probability; only external bookmaker prices and our own official-rating model produce numbers. A value that cannot be confirmed from a source is left blank and flagged rather than estimated. Every row keeps the time it was read, because odds move. No logins, no challenge solving, no wagers.
