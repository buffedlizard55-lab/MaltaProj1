How refresh works

.github/workflows/livelines-457629c4.yml runs every 4 hours (inside the 4–8 h window the brief asks for), on every push that touches this board, and on manual dispatch. It re-reads the Hotspawn Pick'em payload, the outside market feed and the official Valve standings, then runs livelines/build.py and the invariant tests, and commits only if the tests pass — a failed refresh leaves the last good board published and says so here rather than overwriting it.

GitHub treats scheduled runs as best-effort and drops them on inactive repositories, and this repository has many scheduled workflows competing for the same slots: on 2026-10-14 the “Executive board refresh” run 38511378749 failed on main, and the newest build of that board published itself as 8.7 h old. This page therefore prints the age of every input instead of asserting freshness, and the workflow above writes its own result here.
