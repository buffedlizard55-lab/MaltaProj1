Repository-wide irregularities found while reading the board

  • CC-R1 — Hotspawn carries stale fixtures. The server-rendered payload lists far more CS2 fixtures than are playable: every row says status: scheduled, but most have lock times in June/July 2026. Only rows whose lock time is still in the future are picks.
  • CC-R2 — "60/68 matches this week". The lobby header count (68 at 22:19 UTC) is a live, client-computed count across both game titles and does not equal the number of playable CS2 fixtures. The filter panel on the CS2 page counted 85–90 rows, of which only 25 had a future lock time at this snapshot.
  • CC-R3 — no series format on Hotspawn. The payload's best_of / series_format fields are null for every fixture. Series length (Bo1 vs Bo3) is taken from EGamersWorld where shown and is not modelled.
  • CC-R4 — placeholder prices. EGamersWorld shows a generic 1.8 / 1.8 for matches it has not priced (for example FORZE Reload's CCT fixture). Those are not lines and are left blank.
