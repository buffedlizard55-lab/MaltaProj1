Reverse Engineering Hotspawn's Pick'Em Engine

Hotspawn's Pick'em lobby (play.hotspawn.com/lobby) operates as a crowd-sourced esports prediction game with weekly Steam Voucher prize pools ($400 1st place, $200 2nd, $100 3rd, $50 places 4-10).

  • Scoring Formula: Base Points (2-7 pts) × Tier Multiplier (Tier S = ×3.0, Tier B = ×1.5, Tier C = ×1.0) × Streak Multiplier (×1.25).
  • Closing Rules: Picks lock precisely 5 minutes before scheduled match start time.
  • The Pick % Pitfall: Hotspawn displays the percentage of users choosing each team. Crucially, as requested, Hotspawn pick percentages are NOT match probabilities—they reflect public recreational sentiment, fandom, and brand recognition.
