Method & sources

  1. Fixtures — play.hotspawn.com/cs2-pickems is server-rendered Angular; its <script id="ng-state"> TransferState holds the full fixture list (id, teams, competition, tier, scheduled_start_time). Only identity fields are kept; participants*_picked_percent and total_picks are dropped on ingest.
  2. Ratings — official Valve Regional Standings points (global list, 2026-10-05). Each team row links to its exact line in Valve's file and to Valve's per-team details page.
  3. Our line — Valve's own expected-win-rate function (fit.js priorWinExpectation with glicko.js, rd = 75): P(A) = 1 / (1 + 10^(−g·(ptsA − ptsB)/400)), g = 0.972821. Fair decimal odds = 1/P. This closed form is unit-tested against Valve's actual JavaScript.
  4. Roster check — HLTV World Ranking player lists vs VRS rosters (team.js: ≥3 shared players = same team). Ambiguous, missing or mismatched teams → blank + flag. No fuzzy or near-name matching.
  5. Market lines — external bookmaker collection is owned by session 79a1c6c8 (C-02) per COORDINATION.md; this page does not scrape bookmakers.
