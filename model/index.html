  1. Fixtures — play.hotspawn.com/cs2-pickems is server-rendered Angular; its <script id="ng-state"> TransferState holds the full fixture list (id, teams, competition, tier, scheduled_start_time). Only identity fields are kept; participants*_picked_percent and total_picks are dropped on ingest.
  2. Ratings — official Valve Regional Standings points (global list, 2026-10-05). Each team row links to its exact line in Valve's file and to Valve's per-team details page.
  3. Our line — Valve's own expected-win-rate function (fit.js priorWinExpectation with glicko.js, rd = 75): P(A) = 1 / (1 + 10^(−k·(ptsA − ptsB)/400)). Valve's raw curve has k = g = 0.972821, unit-tested against Valve's actual JavaScript. Our line uses the calibrated k = 0.4568 (next item). Fair decimal odds = 1/P.
  4. Calibration (what makes the line ours): Valve's raw curve is overconfident on its own data. We re-fit the slope by maximum likelihood on 6765 matches, each rated with the previous monthly VRS snapshot (Valve's own evaluation recipe; both sides identified by roster). Result: k = 0.4568 vs Valve's 0.972821. Held-out test 2026-08-03..2026-10-05 (n = 1709): log loss 0.66185 → 0.64351, Brier 0.22936 → 0.22575. Raw-curve favourite bins (expected → observed): 55%→56%, 65%→59%, 75%→63%, 85%→77%, 94%→81%. Code: model/calibrate.py, output model/input/vrs/calibration.json.
  5. Roster check — HLTV World Ranking player lists vs VRS rosters (team.js: ≥3 shared players = same team). Ambiguous, missing or mismatched teams → blank + flag. No fuzzy or near-name matching.
  6. Market reference: external bookmaker collection belongs to session 79a1c6c8 (C-02) per COORDINATION.md. This page reads its lines/analysis.csv read-only and recomputes no-vig as (1/oA)/(1/oA+1/oB). Those odds are shown for comparison only. They are never used in our line or pick, and they are not re-verified here (see flag M-S8).
