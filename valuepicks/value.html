Value watches

A value watch is not an upset tip. It means the market price and the project's official-ratings line disagree by at least five percentage points on the same side. The list below is sorted by that gap. Every row keeps its flags: identity, quote age and format caveats are part of the number, and the project line is an uncalibrated estimate, not a book price.

Rules: proportional de-vig of stored decimal odds; project line = 1/(1+10^((points_b - points_a)/400)) on official Valve Regional Standings points with the exact best-of transform; gap = project - market on the better side. Below 5pp the row is a watch, not a value claim.
