Method — how each pick is produced

Deterministic, reproducible by scripts/63ee81ba_build.py; checked by tests/test_63ee81ba.py.

1. Inputs (all source-linked, all timestamped)

  • Open fixture list, team order, tiers, start/lock epochs — Hotspawn /cs2-pickems payload (read 2026-10-14T02:38:00Z; CI capture 2026-10-14T02:18:56Z). Displayed card times run UTC−4 (PF-06); payload epochs are used.
  • Outside moneylines — EGW bc.game (primary, 2026-10-14T02:48:00Z); Pinnacle direct API + Polymarket (cross-checks). Proportional de-vig: p_A = (1/d_A)/(1/d_A + 1/d_B). 1.80/1.80 placeholders rejected (PF-01). Market moneylines are series prices → no format transform.
  • Team ratings — Valve VRS 2026-10-05 (points + line anchors) and HLTV 2026-10-12 (cross-check), verified roster-by-roster on data/8944bb84/ratings.csv.
  • Series format — official HLTV match page per fixture (BO1 for all 12 Elisa BreakOut matches, BO3 elsewhere).

2. Own line (used only when no priced market exists)

  • Map probability: P_map(A) = 1/(1 + 10^(−k·(pts_A − pts_B)/400)) with k = 0.4568 — the slope this repository adopted after MLE calibration on Valve's 6,765 published results (model/input/vrs/calibration.json: log loss 0.6619 raw → 0.6435 calibrated; Brier 0.2294 → 0.2258 out-of-sample).
  • Series transform (independent maps): BO1 → p; BO3 → p²(3−2p).
  • Unrated team → line left blank + flagged. The single exception, LFO 10 (PF-02), publishes a roster-mapped line against VRS #156 Entropy (813 pts) that is labelled RESEARCH on every surface and never counted as verified.

3. Pick rule & confidence

  • Priced market exists → pick = de-vigged favourite; published %s = market de-vig.
  • No priced market → pick = own-line favourite; published %s = own series probabilities.
  • Confidence tiers on the pick probability: OBVIOUS LOCK ≥ 70% · STRONG PICK 60–69% · SOLID LEAN 55–59% · CLOSE TOSS-UP < 55%.
  • Hotspawn crowd pick percentages: 0.0% weight, structurally excluded (the build's inputs contain no crowd fields; test-enforced).

4. Automated refresh (fail-closed)

  • .github/workflows/picks-full-63ee81ba.yml runs hourly + on push: re-runs the repo's live/collect.py (Hotspawn payload, latest VRS file, Pinnacle, EGW, Polymarket, HLTV), rebuilds this board from the live snapshot, runs the test suite, and commits only when tests pass and output changed. Any failure keeps the last good board published (fail-closed).
  • New/renamed fixtures or teams that the mapping cannot verify are published with blank lines + flags, never guesses.
