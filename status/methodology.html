What the numbers mean.

1 / Fixture identity

Hotspawn supplies match identity and scheduling, never match-win probability. This view reads the published collector snapshot, filters CS2 and displays every stored row without substituting an assumed fixed count. Live coverage is not established by a payload row count alone. Locked status is recalculated from each UTC lock timestamp at the browser check time.

2 / External market lines

For paired decimal prices a and b, the project’s margin-removed probability for A is (1/a) / (1/a + 1/b). This is a calculated market estimate, not a source-confirmed true win probability. The independent audit reproduces that arithmetic from stored raw odds, checks complementary percentages and requires an external source rather than Hotspawn.

EGamersWorld is an odds aggregator, not a primary bookmaker. Its linked observations cannot be relabeled as directly verified sportsbook prices by this page. If a public source is inaccessible or absent, the market cell stays blank.

EGamersWorld CS2 coverage · Pinnacle’s official public markets

3 / Originated probabilities

The stored today/ snapshot uses an Elo transform of rating points, as documented in its methodology. The separately maintained VRS model uses its own calibration and published validation. This status view does not silently combine those estimates or infer a probability from team rank. Each displayed model cell is explicitly provisional, with its input links.

Neither sourced rating points nor reproducible arithmetic proves predictive accuracy. Missing ratings stay blank. A displayed pick repeats the supported snapshot estimate; it is not a guaranteed outcome.

4 / Verification, automation and failures

The read-only audit checks stored CS2 row IDs, official fixture source-link presence, UTC timestamps, numerical validity, odds arithmetic, model-input links and all local HTML file/fragment targets. Invalid structural data or broken local links fails the check. Missing odds, stale snapshots and provisional models are published review findings, not silently filled values.

It does not attest that the cited page currently contains the recorded value, that a source link is reachable, or that every live Hotspawn row was captured. That requires live source-level verification. The release-time report is dated; the scheduled audit artifacts provide newer results without overwriting any parallel owner’s dataset.
