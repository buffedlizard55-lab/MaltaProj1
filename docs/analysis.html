Betting Line Analysis

Independent probability estimates from external betting sources vs Hotspawn community picks

Methodology

All probabilities on this dashboard are derived from external betting lines only — never from Hotspawn's own pick percentages. Hotspawn data is shown for comparison only and is not used as an input to our probability estimates.

Primary source: Polymarket prediction markets — these aggregate real-money wagers from informed participants and closely mirror traditional sportsbook implied probabilities.

Secondary sources: Bwin, EGamersWorld, vprognoze.ru, Kalshi, tips.gg, HLTV VRS forecasts, and stavka.tv. Where multiple sources disagree, we report the Polymarket line as primary and flag discrepancies.

Implied probability calculation: 1 / decimal_odds. Note that bookmaker overround means implied probabilities sum to slightly over 100%.
