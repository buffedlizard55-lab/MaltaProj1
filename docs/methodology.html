Methodology — how every number is produced

  1. Fixture list. Only fixtures rendered by the Hotspawn Pick'em lobby (play.hotspawn.com/lobby, CS2 filter) are in scope — 25 pickable + 1 locked pre-snapshot = 26. Each is cross-checked against an independent listing (HLTV match/event pages or EGamersWorld) — see the Reverse-engineering page for why the lobby filter count (85) exceeds the pickable set.
  2. Market probability. Bookmaker decimal odds are taken from EGamersWorld's aggregated bookmaker odds widgets (per-match pages). Implied probability p = 1/odds; the overround is removed proportionally (de-vig): p_A = (1/o_A) / ((1/o_A)+(1/o_B)). Observed overround on this snapshot: ~7.9–8.6%. Odds move — every row carries its snapshot timestamp (2026-10-13 18:47–18:55 UTC).
  3. Our own line (rank model). rating = 2000 − 300·log10(HLTV world rank); P(A) = 1/(1+10^(−(R_A−R_B)/400)). Inputs only from HLTV-sourced ranks in data/ratings.csv. If either rank is unverified the cell stays blank — never inferred.
  4. Pick rule. Market de-vig favorite. If both de-vig probabilities are within 2.0 pts → “No confident pick”. No verified market line → pick only from the rank model (labelled MODEL-PICK); if that is also impossible → “No pick (no verified line)” + flag. H-12 is this week's only such row.
  5. Divergence flag. When the market favorite's market probability and its rank-model probability differ by ≥12.5 pts (H-13, H-24) the row is flagged; H-20 (market 60.9% vs model 49.7%) is additionally called out in the notes as a direction mismatch.
  6. What is never an input: Hotspawn crowd % (display-only), HLTV community/VRS indicator percentages (labelled indicators at most), tournament outrights (never converted to match probabilities).
  7. BO1 caveat. All 12 Elisa BreakOut fixtures are BO1 (per HLTV event 9332): single-map variance is higher; the de-vig market line already prices this, the rank model does not — one more reason the market line carries the pick.

Reproducibility

python3 scripts/model.py regenerates data/matches.csv from data/fixtures.csv + data/lines.csv + data/ratings.csv. python3 scripts/build_docs.py regenerates every page of this site from the CSVs. No hand-entered numbers in the tables.
