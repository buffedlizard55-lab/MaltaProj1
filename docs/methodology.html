Fixtures

Only fixtures that appear in the server-rendered Hotspawn lobby list are used (26 rows, H-01 to H-26). Team names and times are copied verbatim from the Hotspawn label. Hotspawn pick % is recorded as an audit snapshot and is not an input to any probability or pick.

Own line (originated)

Rank-only Elo model, computed by scripts/model.py:

rating = 2000 − 300 · log10(HLTV world rank)
P(A beats B) = 1 / (1 + 10^(−(rating_A − rating_B)/400))

Ranks come from data/ratings.csv (HLTV, 2026-10-12, each row sourced). A team with no verified HLTV rank has a blank own line. We do not infer a rank.

External lines

  • Polymarket (two-outcome prices in cents): used only if the two sides sum to 98–106¢. No-vig P(A) = a / (a+b).
  • eGamersWorld decimal odds (bookmaker not named on page): no-vig P(A) = (1/oA) / (1/oA + 1/oB).
  • Accepted readings feed the external mean. Indicative readings (zero volume) are shown only. Rejected readings (overround outside the rule, or wrong market) are shown only.
  • Tournament outrights (FreeTips, Thunderpick WC) are context only, not match lines.

Pick rule

A side is a pick only when the own line AND the mean accepted external line both put that side at ≥55%. If they disagree, or either source is missing, the result is no pick. A single-source lean is not a pick.

Limits

  • Rank-only model: no roster, map pool, form or news input.
  • Prices are a snapshot at fetch time and move. Re-run the pipeline before relying on them.
  • Analysis only, not betting advice.
