How play.hotspawn.com/lobby actually works

Findings from probing the app on 2026-10-13 (previous session + this session).

  • Rendering. The lobby is server-rendered HTML: the "Closing Soon" + "Upcoming" sections (25 fixtures at 18:06 UTC; 26 at the 17:4x snapshot) are present verbatim in the initial HTML. There is no server-side pagination: ?page=2 and ?offset=25 return the identical first page.
  • Header semantics. Header shows “60 matches this week” while tier/tournament filters count 85 (B 26 + C 55 + S 4). 85 − 25 pickable = 60: the header counts matches in the pool that are not open for picks. The pool includes completed fixtures.
  • Filter pool includes finished events. Verified with Liquipedia: "Urban Riga Open #5" ran Jun 28–29, 2026 and "CCT Europe 2026 Challengers #4" ran Jun 27 – Jul 5, 2026; their teams (ASTRAL, Aimhaus, Coalesce, Leo, 6666, SINQU REHTI, Donstu, Atreides, Misa, Subtop De France, Wampirki, BIG Academy …) appear exactly 1–3× each in the lobby filter — matching those completed runs. → The old F-01 flag (“~60 hidden upcoming fixtures”) is resolved: there are no hidden upcoming fixtures; the pickable set is exactly the server-rendered 25–26.
  • Pickable set grows only as teams are confirmed. The Thunderpick WC tournament page (play.hotspawn.com/tournaments/thunderpick-world-championships) states “Matches appear once both teams are confirmed” and shows “4 matches” (the openers) although the tournament has 14. Later-round fixtures enter the pool later in the week.
  • Backend. Team logos/prizes are served from phpstack-1372681-6459848.cloudwaysapps.com, which answers 404s in NestJS format ({message, error, statusCode}) — the pickem API is a NestJS app on that host. No Swagger at /docs or /docs-json; guessed routes (/matches, /weeks, /api/* on both hosts) all 404. The client-side "load more" endpoint was not discoverable without executing the page JS (fetch tooling here strips scripts; sandbox egress is restricted to git/npm/pypi hosts, so no headless browser).
  • Sitemaps. play.hotspawn.com/sitemap.xml lists only 8 routes (lobby, pickems, tournaments, leaderboard, how-it-works…). The main site's sitemap index additionally exposes tournament/participant/parent-league sitemaps (WordPress).
  • Main-site mirror. www.hotspawn.com/matches is a WordPress archive of the same match data (server-rendered, grouped by day) — useful secondary fixture source; tournament-level URLs like /tournaments/<slug> 404 (only the pickem app has tournament pages).
  • Countdowns. Lock countdowns tick per fixture; the weekly reset counter (~5d 06h at 18:0x UTC Oct 13 → ~Oct 19 00:0x UTC) governs the leaderboard week (week 261 per prize-image URLs).
