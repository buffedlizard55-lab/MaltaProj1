Methodology

1. Fixture set

Rows are read from Hotspawn's public lobby/TransferState identity. At capture, 32 October rows were reconciled (27 carried from the CS2 Pick'em TransferState plus five lobby-only cards) and 59 older summer TransferState rows were retained as stale. No card is fabricated when a match ID is absent.

2. Market line

For a verified decimal pair oA, oB, implied probabilities are (1/oA)/(1/oA + 1/oB) and (1/oB)/(1/oA + 1/oB). This removes the two-way overround. A 1.80/1.80 placeholder, a missing pair, or an in-play/started page is not a line and remains blank.

3. Our line

Our independent CS2 estimate uses the official Valve Regional Standings points snapshot dated 5 October 2026. The reproducible logistic form is P(A)=1/(1+exp(-(pointsA-pointsB)/scale)); BO3 scale = 215.5, BO1 scale = 305.0. The model is not Hotspawn's crowd percentage and does not read it.

4. Pick rule

For an actionable row, use the de-vigged external market favorite first. If no eligible external pair exists, use the VRS model only when both teams have unambiguous points. If neither is confirmed, publish no pick. Completed, live, locked, and stale rows are informational only.

5. Reproduce

python3 scripts/e3315a54_build.py regenerates data/e3315a54/ and mobile/. It reads committed official snapshots for ratings and TransferState, and the session's explicit 21:20 UTC market ledger; no user input or credentials are required.
