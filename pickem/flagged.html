F-01 — Header counts exceed the rendered fixture list

Hotspawn's Pick'em pages state “60 matches this week” / tier counters of 85 (CS2) and 294 (LoL), but the server-rendered pages list 27 CS2 and 231 LoL fixtures. Matches that have already locked, are in progress, or sit beyond the rendered window are not emitted into the page HTML. We publish exactly what the page renders and do not invent the remainder. Source: cs2-pickems, lol-pickems; query-string paging (?page=2, ?offset=26, ?limit=200) returns identical markup (checked 2026-10-13).

F-02 — Hotspawn's “Locks in” countdown contradicts its own printed start time

Every Pick'em card prints a kick-off time and a “Locks in HH:MM:SS” countdown. The printed time is the correct UTC time — verified against two independent HLTV match anchors: (1) 9z vs Aurora: card “Oct 14, 08:30”, HLTV match timestamp data-unix=1791966600000 = 2026-10-14 08:30:00 UTC; (2) HOTU vs fnatic: card “Oct 14, 10:00”, HLTV countdown read at 2026-10-13 18:09 UTC implied 10:00 UTC (HLTV match page). The countdown, however, does not agree with those times: on all 27 CS2 cards it implies a moment +75 minutes after the printed time and on all 231 LoL cards +14 minutes after it (delta histogram: 75 min × 27, 14 min × 231, from the 2026-10-13 18:03 UTC snapshot). The offset is constant per title, so it is a systematic property of Hotspawn's card widget — most plausibly the moment of an internal deadline — not a kick-off clock. We publish the printed (UTC) time and keep the countdown value in the dataset as countdown_implied_start_utc; the discrepancy itself is left unresolved and flagged here.

F-04 — EGamersWorld “1.8 / 1.8” is a default, not a line

5 fixtures display exactly 1.8/1.8 on EGamersWorld (ex-RUSTEC vs mellren, Black Phoenix vs 6666, ex-Keyd Stars vs Galorys, Mental Rush vs SK Gaming Avarosa, Vitality Rising Bees vs G2 Hel). That is EGamersWorld's fallback display when no bookmaker price exists — it is never treated as a line here. Example: ex-RUSTEC vs mellren.

F-05 — Two different prices for the same TWC fixture on one source page

On the Thunderpick World Championship page the price widget showed 9z 3.6 / Aurora 1.27 while the schedule block below it showed 3.8 / 1.22. We publish the widget pair (used consistently for all four TWC fixtures) and note the discrepancy. Source: EGamersWorld TWC event page.

F-07 — Hotspawn crowd percentages drift between snapshots

Observed drift within ~40 minutes on 2026-10-13: ex-Keyd Stars 83% → 86%, Legacy 88% → 83%, 9z 0% → 5%, Astralis 100% → 95%. The crowd figure shown on the site is a snapshot timestamped per row and is metadata only.

F-08 — One fixture only appears on the all-games lobby page

Black Phoenix vs 6666 (CCT Europe #11, Hotspawn id 1079620) was rendered on /lobby but not on /cs2-pickems in the same collection run (the match was live). It is kept with that provenance and its odds are flagged as live/unusable.

F-09 — No published line for the majority of the slate

243 of 258 fixtures have no confirmed bookmaker line. We did not originate substitute probabilities for them: any number would be an invention, and the project rule is explicit that unconfirmable values stay blank. If you want a house model instead (for example an Elo-style model fitted to HLTV ranking points, which are published and linkable), say so and it can be added as a clearly-labelled, separate column.

F-10 — Automated collection is not possible for every source

EGamersWorld, Liquipedia, SofaScore's API and HLTV's schedule pages return HTTP 403 to datacenter clients (GitHub Actions runners), while they render normally in a browser-like fetch; HLTV's analytics pages and ranking pages do return 200. The line rows therefore carry browser-verified values with explicit capture timestamps, and the CI pipeline keeps collecting the fixture inventory automatically (see COORDINATION.md).
